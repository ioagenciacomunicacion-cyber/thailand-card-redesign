# Thailand Privilege Card × Vanessa Meraki - Rate Card

Media kit y propuesta comercial interactiva para la campaña de Thailand Privilege Card × Vanessa Meraki.

## Archivos
- `index.html`: Versión completa interactiva con todas las imágenes y recursos integrados.

## Media kit web
- `media-kit/index.html`: Media kit de Vanessa Meraki convertido en web animada (abrir directamente en el navegador).
- `media-kit/assets/`: fotos, logos de partners y reels extraídos del Google Slides original. Los GIF del deck están convertidos a MP4 ligeros (`assets/reels/`, 14 s en bucle) con póster; se cargan solo al entrar en pantalla.
